## 前提
純 `linear.y` 實測造成車身自轉而非橫移（HANDOVER §15）。要讓側移真的可用，必須先標定「motor id ↔ 實際輪位」與「正占空比時該輪轉向」，再重寫 `mecanum.py` 的符號模式。

## 步驟（需使用者在旁看輪子，或舉起車身）
1. 用 `work/drive-test/wheel_id.py` 逐輪單獨給 25% 占空比，記錄每個 motor id 的**轉向**（從車外側看順/逆時針）與**實際輪位**（前左/前右/後左/後右）
2. 對照 `driver/controller/controller/mecanum.py` 的 `[-motor1, motor3, -motor2, motor4]` 鏡射假設，找出差異
3. 推導正確的符號矩陣（麦克納姆滾子手性也要計入：同側前後輪的符號關係取決於滾子方向）
4. 由 **pi-coder** 修改 `mecanum.py`（先 `.bak-` 備份，`--symlink-install` 故改 src 即生效），重啟走「stop → kill -INT → 確認 ps 空 → start → ~90 s」正確流程
5. 用 `axis_test.py` + 超音波/影像驗證：側移時**前向聲納應幾乎不變**（平行於牆面移動），且視向不移動（不該再自轉）

## 紅線
- 不改厂家源碼以外的東西；不 `colcon build`（除非 `--symlink-install`）
- 每發脈衝 ≤0.5 s、輪子附近清空、先掃視（`pan_scan.py`）
- 若 5 次修復循環內湊不出正確矩陣 → 停手回報，改採「放棄側移」路線
